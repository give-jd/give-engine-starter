Domande frequenti

Sono obbligato a pagare uno di questi per usare Gi.Ve Engine? ▾

No. L'Engine genera codice funzionante. Questi servono solo se vuoi modificarlo parlando con un'AI invece che a mano.

Posso usarne più di uno? ▾

Sì. Molti dei nostri utenti hanno Cursor + Claude Code per i diversi tipi di lavoro.

I miei dati passano da Gi.Ve Engine quando uso Cursor o Windsurf? ▾

No. Gi.Ve Engine non vede nulla dopo che il progetto è stato generato. Sei completamente nelle mani del tuo IDE AI.

Esiste un modo gratuito per usare Claude AI? ▾

Sì: Cursor Hobby gratuito include accesso ai modelli AI con limiti. Per uso intensivo i piani a pagamento sono inevitabili.

BYOK — Bring Your Own Key

Attivo

Inserisci la tua chiave API Anthropic: l'Engine la userà per le sue funzioni interne, pagando i centesimi reali invece di una flat fee. La chiave resta solo sul tuo computer (~/.givengine/credentials.json, permessi 0600) — nessun server Gi.Ve la riceve mai.
